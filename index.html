KEY IDEA

Stability is about what happens after a small disturbance.

An equilibrium is not just a point where the system stops. Stability tells us whether nearby states return, remain nearby, or move farther away.

Asymptotically stable

Nearby solutions converge to the equilibrium.

Unstable

At least one nearby direction moves away.

Semistable

Attraction occurs from one side only.

05 / MATHEMATICAL FOUNDATION

Core concepts

The ideas behind one-dimensional autonomous dynamical systems.

01

Autonomous ODE

dx/dt = f(x)

A first-order autonomous differential equation describes the rate of change of a state variable. The rate depends on x, not explicitly on time.

02

Equilibrium point

f(x*) = 0

At an equilibrium, the derivative is zero. If the system starts exactly at x*, it remains there for all time.

03

Stable equilibrium

|x(0)−x*| small

Lyapunov stability means sufficiently small initial disturbances stay close to the equilibrium for all future time.

04

Asymptotic stability

lim x(t) = x*

An equilibrium is asymptotically stable when it is stable and nearby trajectories also converge to it as time tends to infinity.

ƒ′

Derivative test at an isolated equilibrium

For a smooth one-dimensional system, the derivative gives a quick local test.

06 / PROJECT DOCUMENTATION

How the explorer works

Implementation notes, algorithms, assumptions, and limitations.

DOCS
⌘

Architecture

The application separates mathematical computation from presentation. math-engine.js parses equations, finds roots, classifies equilibria, and integrates trajectories. app.js manages controls, charts, and rendering. styles.css defines the interface.

∫

Numerical methods

Equilibria are estimated by scanning a finite interval, applying bisection to sign changes, and checking local minima of |f| for possible repeated roots. The derivative is estimated with a central difference. Time evolution uses fourth-order Runge–Kutta (RK4).

⌁

Safe expressions

Math.js parses the user's expression. The abstract syntax tree is checked against an allow-list of numeric constants, x, arithmetic operators, and approved mathematical functions before compilation. JavaScript eval() is not used.

◷

Simulation workflow

The RK4 solver precomputes the trajectory for the selected time horizon and step size. The animation reveals stored samples progressively. Reset returns to the initial state; pause and resume control playback without changing the computed solution.

NUMERICAL INTEGRATION

Fourth-order Runge–Kutta update

Four slope estimates are combined at each time step to approximate the next state.

k₁ = f(xₙ)k₂ = f(xₙ + Δt·k₁/2)k₃ = f(xₙ + Δt·k₂/2)k₄ = f(xₙ + Δt·k₃)xₙ₊₁ = xₙ + (Δt/6)(k₁ + 2k₂ + 2k₃ + k₄)
!

Assumptions & limitations

Read these before interpreting a numerical result as a proof.

  • Root detection is numerical and restricted to the displayed interval. Very close roots, roots at singularities, highly oscillatory functions, and difficult repeated roots may be missed or approximated inaccurately.
  • The derivative test assumes a sufficiently smooth function near the equilibrium. When f′(x*) is close to zero, the sign test is used; a truly neutral or non-isolated equilibrium may require a more careful mathematical argument.
  • RK4 is an explicit numerical method. Very large time steps, rapidly growing solutions, or stiff equations can produce inaccurate results. Reduce Δt and compare results to check numerical sensitivity.
  • The interface models a scalar, autonomous, continuous-time system dx/dt = f(x). It does not analyze systems of coupled ODEs, explicit time dependence, or discrete-time maps.
  • External libraries are loaded from a CDN, so an internet connection is required when opening the app for the first time. Once loaded, all equation analysis and simulation run locally in the browser; no backend is used.
